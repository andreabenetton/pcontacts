# Screenshots

Place screenshots here for F-Droid and other app stores.

## Expected files

- `phoneScreenshots/1.png` — launcher / signed-in screen
- `phoneScreenshots/2.png` — settings screen with sync controls
- `featureGraphic/1.png` — 1024×500 feature graphic (optional)

Screenshots should be captured on a stock Android emulator at
1080×1920 (xxhdpi). Do not include status bar content that reveals
personal information.
